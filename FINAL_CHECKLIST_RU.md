# Финальный чек-лист

1. Загрузить содержимое пакета в корень GitHub-репозитория `freelancekit`.
2. Подключить `freelancekit` к Cloudflare Pages. Project name: `freelancekit-tools`; branch: `main`; build command: `exit 0`; output directory: `.`.
3. Проверить live URL.
4. Один раз добавить сайт в Google Search Console и отправить sitemap.
5. При необходимости один раз подключить реальные affiliate-программы и заменить ссылки.

После этого Mac можно выключить.
