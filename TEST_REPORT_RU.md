## Архитектура автономной работы

Исходники находятся в GitHub.

Публичный сайт рекомендуется публиковать через Cloudflare Pages, подключив GitHub-репозиторий. Cloudflare будет автоматически разворачивать каждый push.

GitHub Actions раз в месяц публикует следующий инструмент, пересобирает sitemap и сначала прогоняет тесты. Раз в неделю health check проверяет живой сайт, выполняет тесты и создаёт heartbeat-коммит.

Heartbeat нужен для того, чтобы публичный репозиторий не оставался без активности более 60 дней: GitHub предупреждает, что scheduled workflows в публичных репозиториях могут автоматически отключаться после 60 дней без активности.

## Что не гарантируется

Проверки подтверждают техническую целостность проекта, но не гарантируют поисковый трафик, индексацию, affiliate-одобрение или доход.
